# Submission Runway

로보틱스 · ML/DL · 비전 학회 마감 레이더. PC를 켜면 알림이 뜨고, 바탕화면 한쪽에 카운트다운이 상주합니다.

**앱** → https://hongj97.github.io/conference_radar/

---

## 무엇을 하는가

- 학회 **50건**의 초록·본문 마감을 추적하고, 체크한 것만 알림을 보냅니다
- 마감 **시각과 타임존**을 한국시간으로 환산해 보여줍니다 (AoE 마감은 다음날 20:59, MLSys는 새벽 04:00 같은 함정이 있습니다)
- D-day가 가까울수록 글씨가 굵어지고 붉어집니다 (D-90→D-0 연속 보간)
- 남은 시간은 종이가 넘어가는 플립 카운트다운으로 표시합니다

## 설치 (Windows)

### A. 앱으로 설치하고 부팅 시 자동 실행

**1) PWA 설치**

Chrome에서 https://hongj97.github.io/conference_radar/ 접속 후 둘 중 하나:

- 주소창 오른쪽 끝의 **설치 아이콘**(모니터에 ↓ 표시) 클릭 → `설치`
- 안 보이면 `⋮` → **저장 및 공유** → **페이지를 앱으로 설치…**

Edge라면 `···` → **앱** → **이 사이트를 앱으로 설치**.

설치되면 주소창 없는 독립 창으로 열립니다.

**2) 로그인 시 자동 실행**

- Chrome — `chrome://apps` 접속 → Submission Runway 아이콘 **우클릭** → **로그인 시 앱 시작** 체크
- Edge — `edge://apps` → 앱의 `···` → **시작 설정** → **장치에 로그인할 때 자동 시작** 켜기

위 메뉴가 없는 버전이면 **시작프로그램 폴더**를 쓰면 됩니다. 이 방법이 가장 확실합니다.

1. `Win + R` → `shell:startup` → 열린 폴더에 바로가기 생성
2. 대상:
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --app=https://hongj97.github.io/conference_radar/
   ```
3. 바로가기 **속성** → **실행: 최소화** 로 두면 창이 튀어나오지 않습니다

**3) 알림 켜기**

1. 앱에서 헤더의 `🔔` 클릭 → 브라우저 팝업에서 **허용**
2. **전체 학회** 섹션을 펼치고 **알림 테스트** 버튼으로 실제로 뜨는지 확인

안 뜨면 아래를 순서대로 확인하세요.

| 증상 | 확인할 곳 |
|---|---|
| 권한 팝업이 안 뜸 (이전에 차단함) | `chrome://settings/content/notifications` → 차단 목록에서 `hongj97.github.io` 제거 |
| 권한은 허용인데 안 보임 | Windows 설정 → 시스템 → **알림** → Google Chrome 켜짐 확인 |
| 소리·배너 없이 알림 센터에만 쌓임 | Windows **방해 금지(집중 지원)** 해제 |
| 넘김 애니메이션이 안 보임 | Windows 설정 → 접근성 → 시각 효과 → **애니메이션 효과**. 꺼져 있으면 앱 헤더의 `⇵` 를 눌러 강제로 켜기 |
| 배경화면에서만 넘김이 안 됨 | URL 에 `&anim=1` 이 있는지 확인. Lively 는 앱의 `⇵` 설정을 공유하지 못합니다 |

알림은 **하루 한 번**만 옵니다. 같은 날 여러 번 재부팅해도 조용합니다.

### B. 바탕화면에 상주시키기 (Lively Wallpaper)

**1) Lively 설치** — Microsoft Store에서 `Lively Wallpaper` 검색, 또는 [GitHub 릴리스](https://github.com/rocksdanister/lively/releases)

**2) 배경화면 URL 만들기**

앱에서 **전체 학회** 펼치면 아래에 위치·크기 조절 UI가 있습니다.

1. **목록** 드롭다운에서 무엇을 띄울지 선택
   - `체크한 것` — 지금 체크한 학회를 URL 에 박제. 체크를 바꾸면 Lively 에 다시 등록해야 합니다
   - `자동 · 다가오는 순` ⭐ — 규칙으로 고릅니다. **URL 이 고정이라 다시 등록할 일이 없습니다.** 마감이 지나면 알아서 빠지고 새 학회가 들어옵니다
2. **위치** 드롭다운에서 화면 어느 구석에 붙일지 선택 (9군데)
3. **크기** 슬라이더로 배율 조절 (0.4 ~ 2.5)
4. **미리보기** 버튼을 켜면 바로 아래에 **실제 화면 해상도 비율로 축소한 미니 화면**이 나옵니다.
   브라우저 창 크기가 아니라 `screen.width`×`screen.height` 기준이라, 여기 보이는 비율이 배경화면에서 그대로 재현됩니다.
   (새 탭으로 열어 보면 창이 화면보다 작아 위젯이 실제보다 커 보입니다 — 이 미니 화면으로 판단하세요)
5. 마음에 들면 **바탕화면 URL 복사** — `pos`·`scale`·체크목록이 모두 포함된 완성된 주소가 복사됩니다

> 위치·크기 설정은 저장되므로 다음에 복사할 때도 그대로 유지됩니다.

**3) Lively에 등록**

1. Lively 실행 → **Library** 탭 → 좌측 상단 **`+`** (Add Wallpaper)
2. **Enter URL** 칸에 위 주소 붙여넣기 → 우측 `→` 클릭
3. 목록에 생긴 항목을 클릭하면 바탕화면으로 적용됩니다
4. 모니터가 여러 대면 항목 우클릭 → 적용할 디스플레이 선택

**4) 권장 설정** — Lively `Settings` → `Performance`

| 항목 | 권장 |
|---|---|
| 전체 화면 앱 실행 중 | **일시정지** — 게임·영상 볼 때 GPU 절약 |
| 앱 최대화 시 | 일시정지 |
| 절전 모드 | 일시정지 |

**5) 알아두실 점**

- **Lively는 바탕화면을 통째로 대체합니다.** 위젯이 없는 영역은 기존 벽지가 아니라 이 페이지의 어두운 배경입니다. 쓰던 벽지를 살리려면 그 이미지를 이 저장소에 넣고 `&bg=mywall.jpg` 를 붙이세요
- 바탕화면은 **아이콘·창 뒤**에 깔립니다. `Win + D` 를 누르거나 창이 없을 때 보입니다. 항상 눈앞에 두려면 PowerToys의 **Always on Top**(`Win + Ctrl + T`)으로 앱 창을 고정하는 쪽이 낫습니다
- Lively는 Chrome과 **다른 브라우저 엔진**이라 체크 상태를 공유하지 못합니다. 체크를 바꾸면 **바탕화면 URL 복사**를 다시 눌러 Lively 주소를 갱신해야 합니다
- 배경화면 모드는 읽기 전용입니다. 클릭·체크는 되지 않습니다
- 크기가 예상과 다르면 URL 끝에 `&debug=1` 을 붙여 보세요. 뷰포트 크기와 DPR 이 하단에 찍힙니다

## URL 파라미터

| 파라미터 | 값 | 설명 |
|---|---|---|
| `mode` | `wall` | 읽기 전용 배경화면 뷰 |
| `pos` | `tl` `t` `tr` `l` `c` `r` `bl` `b` `br` | 화면 어느 구석에 붙일지 (기본 `tl`) |
| `scale` | `0.4` ~ `2.5` | 전체 크기 배율 (기본 `1.0`). 기준 단위는 고정 `15px` 라 모니터가 바뀌어도 같은 물리 크기 |
| `debug` | `1` | 하단에 뷰포트 크기·DPR·계산된 단위·슬롯 수 표시. 크기가 예상과 다를 때 진단용 |
| `bg` | 이미지 경로 | 배경 이미지. Lively는 벽지를 통째로 대체하므로, 기존 벽지를 쓰려면 이미지를 이 저장소에 넣고 지정 |
| `s` | base64 | 체크한 학회 비트마스크 (고정 목록) |
| `s` | `auto` | **규칙 기반.** 확정 + 마감 미도래 항목을 가까운 순으로. URL 이 고정됩니다 |
| `tier` | `0123` | 자동 모드에서 포함할 등급. `0`=국내 (기본 전체) |
| `days` | 숫자 | 자동 모드에서 N일 이내만 (기본 제한 없음) |
| `est` | `1` | 자동 모드에서 예상 일정도 포함 (기본 제외) |
| `field` | `robotics,vision` | 자동 모드에서 분야 제한 (기본 전체) |
| `all` | `1` | 자동 모드에서 `skip` 항목(저널 트랙·커밋 단계)도 포함 |
| `anim` | `1` / `0` | 종이 넘김 효과 강제. **Lively 에서는 필수** — 다른 브라우저라 앱의 토글 설정을 못 읽고, Windows 애니메이션이 꺼져 있으면 효과가 사라집니다 |

## 데이터 수정

`conferences.json` 하나만 고치면 됩니다. push하면 바로 반영됩니다.

```jsonc
{
  "idx": 4,                    // 영구 고정. 재사용·재정렬 금지 (배경화면 비트마스크가 의존)
  "id": "icra-2027",
  "tier": 1,                   // 1 최상위 / 2 상위 / 3 준수
  "est": false,                // true = 마감일이 공식 발표 전 추정치
  "def": true,                 // 초기 체크 여부
  "abs":   { "at": "...", "label": "AoE", "sure": true },   // 초록 (없으면 null)
  "paper": { "at": "2026-09-15T23:59:00-07:00", "label": "23:59 PST", "sure": true }
}
```

- `at` — ISO 8601 + UTC 오프셋. **AoE는 `-12:00`**, PST `-08:00`, PDT `-07:00`
- `sure` — `false`면 공식 시각이 없어 AoE 23:59로 추정한 것 (화면에 `?` 표시)
- `skip` — `true`면 자동 모드에서 제외. 신규 논문 투고 마감이 아닌 항목(저널 트랙, ARR 커밋 단계)에 붙입니다
- 새 학회는 `idx`를 다음 번호로 부여합니다. 기존 번호를 바꾸면 저장된 체크 목록이 어긋납니다
