# Submission Runway

로보틱스 · ML/DL · 비전 학회 마감 레이더. PC를 켜면 알림이 뜨고, 바탕화면 한쪽에 카운트다운이 상주합니다.

**앱** → https://hongj97.github.io/conference_radar/

---

## 무엇을 하는가

- 학회 **50건**의 초록·본문 마감을 추적하고, 체크한 것만 알림을 보냅니다
- 마감 **시각과 타임존**을 한국시간으로 환산해 보여줍니다 (AoE 마감은 다음날 20:59, MLSys는 새벽 04:00 같은 함정이 있습니다)
- D-day가 가까울수록 글씨가 굵어지고 붉어집니다 (D-90→D-0 연속 보간)
- 남은 시간은 종이가 넘어가는 플립 카운트다운으로 표시합니다

## 설치 (Windows)

### 1. 앱 + 부팅 알림

1. Chrome/Edge에서 위 주소 접속 → 주소창 우측 **설치** 아이콘 클릭
2. `chrome://apps` → 앱 우클릭 → **"로그인 시 앱 시작"** 체크
3. 첫 실행 시 **알림 권한 허용**

알림은 하루 한 번만 옵니다. Tier별로 시점이 다릅니다.

| 대상 | 알림 시점 |
|---|---|
| T1 확정 | D-60 / 30 / 14 / 7 / 3 / 1 / 당일 |
| T2 확정 | D-30 / 14 / 7 / 1 |
| T3 확정 | D-14 / 3 |
| 예상 일정 | D-45 (1회) |

### 2. 바탕화면 상주 (선택)

[Lively Wallpaper](https://github.com/rocksdanister/lively) 설치 후, 웹 URL 벽지로 아래 주소를 등록합니다.

```
https://hongj97.github.io/conference_radar/?mode=wall&pos=tr&scale=0.62&s=<체크목록>
```

`<체크목록>`은 앱의 **바탕화면 URL 복사** 버튼이 만들어 줍니다. Lively는 별도 브라우저라 체크 상태를 공유하지 못해, 체크를 바꾸면 URL을 다시 복사해 갱신해야 합니다.

## URL 파라미터

| 파라미터 | 값 | 설명 |
|---|---|---|
| `mode` | `wall` | 읽기 전용 배경화면 뷰 |
| `pos` | `tl` `t` `tr` `l` `c` `r` `bl` `b` `br` | 화면 어느 구석에 붙일지 (기본 `tl`) |
| `scale` | `0.35` ~ `2.0` | 전체 크기 배율 (기본 `1.0`) |
| `bg` | 이미지 경로 | 배경 이미지. Lively는 벽지를 통째로 대체하므로, 기존 벽지를 쓰려면 이미지를 이 저장소에 넣고 지정 |
| `s` | base64 | 체크한 학회 비트마스크 |

## 데이터 수정

`conferences.json` 하나만 고치면 됩니다. push하면 바로 반영됩니다.

```jsonc
{
  "idx": 4,                    // 영구 고정. 재사용·재정렬 금지 (배경화면 비트마스크가 의존)
  "id": "icra-2027",
  "tier": 1,                   // 1 최상위 / 2 상위 / 3 준수
  "est": false,                // true = 마감일이 공식 발표 전 추정치
  "def": true,                 // 초기 체크 여부
  "abs":   { "at": "...", "label": "AoE", "sure": true },   // 초록 (없으면 null)
  "paper": { "at": "2026-09-15T23:59:00-07:00", "label": "23:59 PST", "sure": true }
}
```

- `at` — ISO 8601 + UTC 오프셋. **AoE는 `-12:00`**, PST `-08:00`, PDT `-07:00`
- `sure` — `false`면 공식 시각이 없어 AoE 23:59로 추정한 것 (화면에 `?` 표시)
- 새 학회는 `idx`를 다음 번호로 부여합니다. 기존 번호를 바꾸면 저장된 체크 목록이 어긋납니다

## 등급 출처

- **CCF** — 중국컴퓨터학회 추천 국제학술회의 목록 2022판
- **CORE** — ICORE Portal, CORE2023
- **h5** — Google Scholar Metrics

Tier는 위 셋을 종합한 이 앱의 자체 지표입니다. 소속 기관의 공식 평가 기준이 따로 있다면 그쪽이 우선합니다.

> 학회는 SCI/SSCI가 될 수 없습니다. SCI·SCIE·SSCI는 Web of Science의 *저널* 색인이고,
> 학술대회 논문집은 별도 색인인 CPCI-S에 등재되며 Impact Factor가 부여되지 않습니다.
